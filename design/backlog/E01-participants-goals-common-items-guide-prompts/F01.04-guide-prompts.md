# F01.04 Guide prompts

**Outcome:** managers set the organisation's guide prompts, the placeholder text shown in an empty Guided notes box
(D12, D34), up to 1,000 characters, and are warned before leaving the page with unsaved changes (design.md §4.10).

### Notes
- Blocking the Android back gesture and iOS swipe-back is unverified (guide-prompts.md open questions); try both on
  real phones in this story.
- From S00.04.06 (13 October 2026, its task 5): Sign out, in the Account panel (`AccountPanel` in
  `src/routes/Header.tsx`), was built without the leave guard's steps, as `leaveGuard.ts` did not exist, and with no
  stand-ins for them. This story adds them with `leaveGuard.ts` (settings-textarea.md), in the order of app-shell.md's

  0), so that **Stay** sends nothing; `disarmUnloadGuard()` before the reload (step 3, just before the logout
  request); and `rearmUnloadGuard()` after a failed logout. The comment over `signOut()` that names the missing steps
  then drops this story's part. If S00.04.08 is done by then, its reload for a different person, through
  `fullPageLoad.ts`, gets `disarmUnloadGuard()` first too (app-shell.md, settings-textarea.md).
