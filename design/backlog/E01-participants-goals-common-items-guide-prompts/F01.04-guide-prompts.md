# F01.04 Guide prompts

**Outcome:** managers set the organisation's guide prompts, the placeholder text shown in an empty Guided notes box
(D12, D34), up to 1,000 characters, and are warned before leaving the page with unsaved changes (design.md §4.10).

## Stories
- S01.04.01 Set the guide prompts
- S01.04.02 Warning before leaving unsaved prompts

## Feature checks
Owns these rows in [coverage.md](../coverage.md):
- design.md §14 M1 *Scope*, "and the guide prompts".
- `guide-prompts.md › Access and structure`, `› Loading`, `› Field`, `› Limit and count`, `› Save`, `› Leaving`.

Other guide-prompts.md groups: Effect on the note form (a cross-check at M2) is E02's; Storage and naming and
Accessibility runs are Definition of Done rows.
