# F00.01 Skeleton and continuous integration

**Outcome:** one ASP.NET Core 10 app serves the React SPA and the API from the same origin, every pull request is
built and tested in CI, and the shared building blocks that every screen uses (tokens, buttons, loading and error
handling, the copy module and its checks) exist once.

## Stories
- S00.01.01 Serve the SPA and the API from one origin
- S00.01.02 Build and test every pull request
- S00.01.03 Shared look, buttons and page status
- S00.01.04 Shared loading, failure and form-error handling
- S00.01.05 Copy module, date formats and wording checks

## Feature checks
Owns this row in [coverage.md](../coverage.md): design.md §14 M0 *Scope*, "ASP.NET Core on .NET 10 LTS serving the
React (Vite, TypeScript) build from the same origin; unknown `/api` paths return 404."

The building blocks in S00.01.03–S00.01.05 own no coverage row of their own. They are the first build of mechanisms
that the Definition of Done ([README §9](../README.md#9-definition-of-done)) checks on every story.
