# F00.07 Sign-in choices

**Outcome:** at setup, anyone invited (a worker, a manager or Support) can choose how they sign in: a passkey, a
password and an authenticator app, a password only, or a password and a passkey (D97). A second step is offered to
everyone and required of no one. The first two work exactly as before; this feature adds the other two.

## Stories
- S00.07.01 Set up and sign in with a password only
- S00.07.02 Set up and sign in with a password and a passkey

## Feature checks
Also delivers these rows in [coverage.md](../coverage.md), which F00.04 owns (E00 rows 1 and 4), linked and not
copied:
- design.md §14 M0 *Done when*, "A manager and a worker can each accept an invite, choose how to sign in and sign in
  that way ... (every setup path, D97)".
- design.md §14 M0 *Scope*, "Accounts: invite and setup (any of the four sign-in methods, D97)".

It owns D97 itself, which has no coverage row: the four ways to sign in, and the amended rules in D23, D51, A22, A34
and design.md §8.1.
